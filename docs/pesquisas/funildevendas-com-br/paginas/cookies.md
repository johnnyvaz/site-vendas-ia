## Limpando os dados de navegação

Algumas atualização no Funil de Vendas™ podem impedir navegadores lerem as oportunidades, não se preocupe, todas as informações estão segurança. Se isto está acontecendo em seu acesso, siga os procedimentos para limpar os dados de navegação:

## ![](/~funildev/wp-content/uploads/2017/11/cookie.png)

## Chrome

![](/~funildev/wp-content/uploads/2017/11/chrome-899x1024.jpg)

  1. No computador, abra o Chrome.
  2. No canto superior direito, clique em Mais !(//storage.googleapis.com/support-kms-prod/5C6FB52C8BBB2C12DC89B5F42F16B9B5E9CF).
  3. Clique em **Mais ferramentas!(//lh3.googleusercontent.com/LaAImojMiWBD2bzgFDyPZ2XEyr1Go8l68cDpipMNiC3c_rPvHfYrnz1EH2pcESxgnN0=w13-h18) Limpar dados de navegação**.
  4. Na caixa exibida na parte superior da tela, escolha um período, como **a última hora** ou **o dia anterior**. Para excluir tudo, selecione **o começo**.
  5. Selecione 3 primeiras opções e as 2 últimas
  6. Clique em **Limpar dados de navegação**.

## Firefox

**Entre no link:**<https://support.mozilla.org/pt-BR/kb/excluir-historico-de-navegacao-pesquisa-download>

## Microsoft Edge

**Entre no link:** <https://privacy.microsoft.com/pt-br/windows-10-microsoft-edge-and-privacy>
