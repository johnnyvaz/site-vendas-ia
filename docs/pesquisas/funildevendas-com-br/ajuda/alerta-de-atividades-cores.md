# Alerta de Atividades (Cores)

- **Modificado:** 2025-07-30T12:46:30

Temos 3 tipos de alertas para as atividades:

🟢 **Alerta verde:** Atividade dentro do prazo;

🟡**Alerta amarelo:** Atividade dentro do prazo, porem com vencimento no dia útil;

🔴**Alerta em vermelho:** Atividade em atraso, aonde já deveria ter sido concluída/realizada.

**Obs:** Lembre-se que é de extrema importância todas as oportunidades terem uma atividade vinculada a ela e se atentar aos sinais de alerta.
