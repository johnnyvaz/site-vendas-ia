# Adicionar Oportunidades

É extremamente importante adicionar suas oportunidades para dar sentido ao seu Funil de Vendas.

Você pode adicionar oportunidades em seu Funil de Vendas de “3” formas:

**1 *Integração** com sites, Landing Pages, Squeeze Pages, etc. Também com outros CRMs como entrada de dados.  
​**2** Importação de planilhas no formato “**xlsx** ”.  
​**3** Manualmente pelo Botão “**\+ Oportunidades** ”.
