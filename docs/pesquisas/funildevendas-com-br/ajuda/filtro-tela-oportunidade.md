### Lista de filtros

  * Ordenar: Alfabética crescente, Alfabética decrescente, Data crescente, Data decrescente, Atividades crescente, Atividades decrescente, Sem atividades
  * Classificação: Todas oportunidades, Novas oportunidades
  * Status: Abertas, Ganhas, Perdidas, Futuras
  * Respostas: Lista de respostas de Perda e Ganho
  * Usuários: Lista de usuários ativos no CRM
  * Oportunidade: Campo de texto para localizar por Pessoa, Organização, Título da Oportunidade ou Telefone
  * Produto: Lista de Produtos cadastrados no CRM
  * Canal de Vendas: Lista de Canais de Vendas cadastrados no CRM
  * Segmento: Lista de Segmentos cadastrados no CRM
  * Período: Seleção de data De | Até
  * Oportunidades compartilhadas: Exibir, Não exibir
