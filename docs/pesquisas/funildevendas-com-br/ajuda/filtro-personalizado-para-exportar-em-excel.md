# Filtro personalizado para exportar em Excel

- **Modificado:** 2025-07-29T20:41:29

Filtros do Funil de Vendas | Exportar Oportunidades

Para exportar suas oportunidades em Excel filtrando apenas o que deseja, na tela de oportunidades, clique sobre o **ícone (Lista)** e espere a tela de Visualizar em Lista carregar.

  1. Clique no ícone (Lupa) e selecione o que deseja

  2. Selecione os filtros principais conforme sua necessidade

  3. Clique no botão azul (Exportar Tudo)

![](https://funildevendas.com.br/wp-content/uploads/2025/07/Filtro_Exportar_Lista-1024x564.gif)

**Observação:** Para exportações com mais de 2.000 registros, o Funil de Vendas enviará para uma lista processamento e ao concluir disparará um e-mail para você com o link do arquivo. **Este arquivo estará disponível por 7 dias.** Você pode acessar-lo também em **Configurações > Exportar Oportunidades**
