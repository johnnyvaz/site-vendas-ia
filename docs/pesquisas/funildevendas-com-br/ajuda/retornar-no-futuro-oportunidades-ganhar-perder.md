# Retornar no futuro (Oportunidades Ganhar / Perder)

- **URL:** https://www.funildevendas.com.br/ajuda/retornar-no-futuro-oportunidades-ganhar-perder/
- **Data:** 2025-07-29T20:03:03
- **Modificado:** 2025-07-29T20:03:03

---

O retornara tem a função de criar uma mascara da oportunidade para quando chegar a data selecionada ser aberta a oportunidade.

Ao habilitar a opção “Sim”, quando uma oportunidade é ganha ou perdida, aparecerão opções para selecionar uma data e a etapa para a qual a oportunidade futura será direcionada.

![](https://funildevendas.com.br/wp-content/uploads/2025/07/image-3-1024x310.png)

Essa funcionalidade cria uma cópia da oportunidade original, que será reativada na data selecionada, mantendo o histórico completo, exceto pelas atividades da oportunidade anterior, evitando assim a duplicidade de atividades.
