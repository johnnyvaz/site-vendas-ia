# Como adicionar uma anotação na oportunidade?

- **URL:** https://www.funildevendas.com.br/ajuda/como-adicionar-uma-anotacao-na-oportunidade/
- **Data:** 2025-07-30T12:50:33
- **Modificado:** 2025-07-30T12:50:33

---

Para adicionar uma anotação na oportunidade, você pode fazer isso em duas formas.  
A primeira é na atividade, quando estiver cadastrando uma nova atividade, basta clicar no campo de anotação e colocar a informação, ou depois da atividade cadastrada clique para alterar a atividade, e faça o mesmo procedimento. A segunda forma de colocar anotação na oportunidade é indo no diário de bordo, basta clicar no botão anotação e colocar a informação desejada.

![](https://funildevendas.com.br/wp-content/uploads/2025/07/Captura-de-Tela-2025-07-30-as-09.47.59-1024x543.png)

**Importante:** _Em atividade é possível colocar informações simples, com pequenos textos, se a anotação que será trabalhada for um texto, é possível colocar ele em diário de bordo._
