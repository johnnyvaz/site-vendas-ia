# Reabrir Oportunidades Ganhas ou Perdidas

- **URL:** https://www.funildevendas.com.br/ajuda/reabrir-oportunidades-ganhas-ou-perdidas/
- **Data:** 2025-07-30T12:45:23
- **Modificado:** 2025-07-30T12:45:23

---

Se você tiver a permissão concedida pelo usuário master, poderá reabrir oportunidades que foram marcadas como ganhas ou perdidas. Siga os passos abaixo para realizar essa ação:

  * Faça o Filtro de Oportunidades Ganhas ou Perdidas.

![](https://funildevendas.com.br/wp-content/uploads/2025/07/Captura-de-Tela-2025-07-30-as-09.41.11-1024x450.png)

  * Se necessário, ajuste o período para facilitar a localização da oportunidade desejada.

![](https://funildevendas.com.br/wp-content/uploads/2025/07/Captura-de-Tela-2025-07-30-as-09.41.55-1024x455.png)

  * Selecione a Oportunidade.

  * Clique na oportunidade selecionada para abrir os detalhes.

![](https://funildevendas.com.br/wp-content/uploads/2025/07/Captura-de-Tela-2025-07-30-as-09.42.44-1024x455.png)

  * Dentro dos detalhes da oportunidade, localize o botão “Ação”.

  * Clique no botão “Ação” e você verá a opção de reabrir a oportunidade.

  * Selecione a opção de reabrir.

![](https://funildevendas.com.br/wp-content/uploads/2025/07/Captura-de-Tela-2025-07-30-as-09.43.24-1024x451.png)

Prontinho! A oportunidade agora será reaberta e retornará para a mesma etapa em que estava antes de ser marcada como ganha ou perdida.

**Obs: Lembrando, utilize esta função apenas se a oportunidade foi marcada como ganha ou perdida indevidamente.**
