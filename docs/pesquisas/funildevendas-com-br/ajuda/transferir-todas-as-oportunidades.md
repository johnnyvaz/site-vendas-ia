Este é um recurso muito importante, transfira as oportunidades de um membro para outro, ou alternando entre funis em caso de necessidade.

![](https://funildevendas.com.br/wp-content/uploads/2025/07/Barra-Superior.png)

Clique sobre o nome cadastrado **>** Configurações **>** Transferir Oportunidades **>**

*Somente com permissão da conta de Administrador  
*Somente usuário gestor pode transferir

## Transferência de Oportunidades

  * Clique no botão “Filtro”

  * No campo de busca inclua o nome do usuário que contenha as oportunidades

  * Selecione o período inicial

  * Selecione o período final (para a data atual também)

  * Clique em Filtrar

  * Observe a coluna “Usuário” se o nome filtrado corresponde ao que filtrou

  * Desça sua tela até atualizar todas as oportunidades deste usuário

  * Volte ao topo, abaixo do botão “Transferir” clique na caixa de seleção para selecionar tudo

  * No filtro “Transferir para” selecione o usuário que irá receber as oportunidades

  * No filtro “Funil” selecione o funil que receberá as oportunidades

  * Clique em Transferir
