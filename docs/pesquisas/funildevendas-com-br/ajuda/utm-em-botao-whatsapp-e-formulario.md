Track de utm na captura do lead

Se você já trabalha com campanhas de trafego pago, este é um recurso avançado para medir de onde estão vindo os leads com precisão.

**É possível mapear as utms**  
utm_source

utm_campaign

utm_term

url

## Como usar?

Basta apontar na campanha os utms junto com a url.  
​

**Exemplo:**
    
    
    https://www.meusite.com.br/lpcampanha/?**utm_source** =FaceBookADS&**utm_campaign** =DiaDasMaes&**utm_term** =pesquisa%20com%20cliente

O código fonte do formulário ou botão WhastApp será capaz de capturar estas informações.

Os campos são opcionais mas se você deseja exibir a informação em todas as oportunidades, eles deverão ser criados no Modulo Oportunidade.

Configurações > Personalizar campos > Aba oportunidade
