🚀 O que é o Disparo Rápido?

É uma extensão para Google Chrome que permite enviar mensagens em massa pelo WhatsApp Web de forma automatizada, individual e segura, sem depender de listas de transmissão ou grupos.

É ideal para autônomos, lojistas, profissionais liberais e infoprodutores.

🔧 Como Funciona

Instalação: baixe a extensão no Google Chrome.

Carregue contatos: importe via Excel (.csv) ou grupos do WhatsApp.

Configure intervalos: defina tempo entre disparos para evitar bloqueio.

Envie mensagens: textos, imagens, áudios e vídeos.

Tudo é feito dentro do WhatsApp Web.

🎯 Funcionalidades

Disparos ilimitados com valor fixo.

Importação de contatos via planilha ou grupos.

Intervalos personalizáveis entre mensagens.

Acompanhamento em tempo real dos envios.

Suporte a mídia: áudio, vídeo, imagens e arquivos.

Instalação simples e sem pesar no computador.
